# Front-End Assessment

## Project Overview
This project is a front-end implementation based on the provided Figma design.  
The goal was to accurately reproduce the UI and integrate API data while maintaining clean and reusable code architecture.

---

## Tech Stack

- React JS
- React Bootstrap
- Axios (for API integration)
- CSS

> Note: TypeScript and Tailwind were optional, so this project is implemented using standard React and CSS for simplicity and clarity.

---

## Features

- Pixel-perfect UI based on Figma
- Fully responsive design (mobile, tablet, desktop)
- Reusable components structure
- API integration with loading & error handling
- Clean and maintainable code
